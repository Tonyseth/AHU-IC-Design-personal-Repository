## 简答

1. 51单片机内部存储器分为几个区域？各自作用？
   内部存储器分为：

   1. 00H-1FH 通用寄存器区。该区域存储4组通用寄存器，由PSW的RS0和RS1决定工作寄存器组。
   2. 20H-2FH 可位寻址区。 该区域可以字节地址寻址也可以位地址寻址。
   3. 30H-7FH 数据缓冲区。 该区域为真正的数据缓冲区，一般把堆栈区设置在此。
   4. 80H-FFH 特殊寄存器区。 该区域存储了21个特殊功能寄存器。

2. 51单片机的指令系统按功能分为哪几类？

   分为5类：

   1. 数据传送类
   2. 算术运算类
   3. 逻辑运算与移位类
   4. 位操作类
   5. 控制转移类

3. 51单片机中断响应和中断返回的流程？

   1. 中断响应的过程：
      1. 中断采样：中断标志对外部中断源，在机器每个周期的S5P2采样。当中断被触发，置位中断标志。
      2. 中断查询：在每个机器周期的S6按照中断优先级查询中断标志。
      3. 中断响应：当中断标志位被置位，先保护断点，然后将对应中断源的中断矢量地址传给PC，执行中断服务函数
   2. 中断返回的过程：
      1. 将断点位置传入PC
      2. 跳回断点继续执行原来的代码，等待中断

4. 晶振12MHz，定时/计数器工作在模式0/1/2时，各自的最大定时时间？

   t_mc = 12/f_osc = 1us

   1. 工作模式0：t = 2^13 * 1us
   2. 工作模式1：t = 2^16 * 1us
   3. 工作模式2：t = 2^8 * 1us

5. 什么是串行异步通信？数据帧格式？

   串行异步通信指的是这样一种数据传输方式：按照数据顺序，从低位到高位逐位传输数据，传输过程收发双方使用各自的时钟，通过数据帧来确保传输准确。

   一个数据帧包含：

   1. 起始位：1位数据，低电平。
   2. 数据位：5到8位。
   3. 奇偶校验位：1位校验位，根据需要选择奇校验或者偶校验。
   4. 停止位：高电平，1位或1位半或2位。
   5. 空闲位：在两个数据帧中按需要插入高电平，标志着该线空闲。

6. 从外部RAM 8000H 把数据送到外部RAM 0010H。

   ```assembly
   ORG 0000H
   LJMP MAIN
   ORG 1000H
   MAIN:
   MOV DPTR, #8000H
   MOVX A, @DPTR
   MOV DPTR, #0010H
   MOVX @DPTR, A
   END
   ```

## 程序设计

1. 将片外RAM从1000H位置开始的数据，搬运到片内RAM20H开始，遇到0停止。

```assembly
ORG 0000H
LJMP MAIN
ORG 2000H
MAIN:
MOV DPTR, #1000H
MOV R0, #20H
LOOP:
MOVX A, @DPTR
JZ $
MOV @R0, A
INC DPTR
INC R0
SJMP LOOP
END
```

2. 单片机的振荡频率为12MHz，用定时器/计数器0编程实现从P1.0输出周期为500μs的方波。

``` assembly
ORG 0000H
LJMP MAIN
ORG 000BH
CPL P1.0
RETI
ORG 2000H
MAIN:
MOV TMOD, #02H
MOV TH0, #06H
MOV TL0, #06H
SETB ET0
SETB EA
SETB TR0
SJMP $
END
```
